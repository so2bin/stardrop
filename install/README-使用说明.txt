星传 StarDrop · 使用说明
========================================

一句话：手机不用装 App，扫码就能把照片/视频原图传到这台电脑。

【怎么用】
1. 双击桌面的「星传 StarDrop」。
2. 手机连上与电脑相同的 Wi‑Fi（华为星闪网络、手机热点也可以）。
3. 用手机相机 / 浏览器扫窗口右侧二维码，打开「星传」页面。
4. 点「选择照片 / 视频」，或直接「拍照」。传完会自动存到：
   C:\Users\<你的用户名>\Pictures\星传\<日期>\
5. 电脑上的文件也可以拖进窗口，手机会在「电脑发来的文件」里看到，点一下下载。

【为什么不用装手机 App】
手机端就是一个网页，iPhone / 安卓 / 鸿蒙都能用；电脑端用 Tauri + 本地 HTTP 服务，
照片只在同一局域网内直传，不经过任何服务器。

【配对码 / 端口】
首次启动会生成 4 位配对码，并自动记住端口和配对码。
下次启动不变，手机浏览器收藏一次即可，不用每次重新扫码。
（如果端口被其它程序占用，会自动换一个并记住新的。）

【手机打不开页面？】
· 确认手机和电脑在同一网络（不要开访客网络隔离 / AP 隔离）。
· 点应用里的「修复连接」，在 Windows 弹窗里允许防火墙。
· 电脑如果装了安全软件，请放行 StarDrop.exe 的局域网访问。

【文件在哪】
收到的文件：C:\Users\<用户名>\Pictures\星传\<日期>\
应用数据：  C:\Users\<用户名>\AppData\Local\StarDrop\
程序目录：  C:\Users\<用户名>\AppData\Local\Programs\StarDrop\

【卸载】
运行程序目录里的「卸载.cmd」即可（不会删除已经收到的图片）。
